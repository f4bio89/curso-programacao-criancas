# Preparação do Pop!_OS (adulto)

## O necessário

1. Confirme que Python 3 existe: abra Terminal e execute `python3 --version`.
2. Instale **Thonny** pela Pop!_Shop procurando “Thonny”, ou com o comando seguro abaixo:
   ```bash
   sudo apt update
   sudo apt install thonny
   ```
   Este é o único documento que usa `sudo`; execute-o apenas o adulto, antes do curso.
3. Para Scratch, abra https://scratch.mit.edu/ no navegador. Usar no navegador evita instalação adicional.
4. Crie na Área de Trabalho uma pasta chamada `Projetos_Python` para a Missão 12.

## Não é necessário

Não instalar bibliotecas Python, Docker, IDE pesada nem extensões de navegador. Os códigos usam apenas a biblioteca padrão do Python.

## Privacidade

Não coloque dados reais da criança em contas, projetos públicos ou prompts de IA. Para Scratch, o login é opcional; salvar localmente também é possível.
