# 🚀 Curso de Computação e Programação: Missões da Inventora

Um curso doméstico de **24 missões práticas**, criado para uma criança de aproximadamente 10 anos que começa do zero no Pop!_OS Linux. O objetivo não é decorar Python: é ganhar confiança, curiosidade, autonomia e prazer em criar.

## Como usar

- Faça **duas missões por semana**, em sessões de 35–45 minutos.
- Abra primeiro `missao_XX/guia_professor.md`; depois entregue `missao_XX/missao.md` à criança.
- A criança controla mouse e teclado sempre que possível. O adulto faz perguntas e oferece pistas; não toma o controle.
- Marque habilidades em `PROGRESSO.md` e conquistas quando forem merecidas.
- Cada missão deixa algo para mostrar: arquivo, jogo, história, mapa, desenho ou explicação.

## Filosofia: explorar → descobrir → criar → errar → corrigir → modificar → explicar

Bugs são pistas, não fracassos. Não diga “você fez errado”; diga **“encontramos um bug; o que ele está nos contando?”**. A explicação vem depois da necessidade: primeiro aparece um problema interessante; então a criança descobre a ferramenta para resolvê-lo.

## Ferramentas

- Pop!_OS: Arquivos, navegador e terminal (somente comandos seguros, mais tarde).
- [Scratch](https://scratch.mit.edu/) para as missões 07–11. Pode ser usado no navegador; o adulto prepara login somente se quiser salvar on-line.
- [Thonny](https://thonny.org/) + Python 3 para as missões 12–24.
- Papel, lápis e materiais simples nas missões offline.

Veja `setup/instalar_ferramentas.md` e `setup/verificar_ambiente.md` antes da Missão 01.

## Fases

1. **Exploradora Digital (01–03):** computador, arquivos, internet e segurança.
2. **Pensando como Programadora (04–06):** instruções, padrões e decisões sem tela demais.
3. **Scratch (07–11):** criar e testar um jogo visual completo.
4. **Python (12–18):** perceber que blocos viram palavras escritas para criar programas.
5. **Jogos e Programas (19–22):** combinar ideias em projetos pequenos e divertidos.
6. **Projeto Final (23–24):** escolher, construir, testar e apresentar algo próprio.

## Preparação manual que exige adulto

- Missão 02: escolher exemplos seguros de links/mensagens fictícias; nunca usar dados pessoais reais.
- Missão 07: abrir Scratch e confirmar que o som/navegador funcionam.
- Missão 12: abrir Thonny e criar uma pasta `Projetos_Python` na Área de Trabalho.
- Missões 23–24: reservar espaço para a apresentação e, se desejado, convidar família.
